# User Guide: Local Prayer Time Calculations

## Introduction

This guide explains how to use the new Local Prayer Time Calculation feature in the HaramBlur app. This feature allows you to get accurate prayer times without needing an internet connection, with special support for Morocco's official prayer time calculation methods.

## What is Local Prayer Time Calculation?

Local Prayer Time Calculation is a feature that calculates prayer times directly on your device instead of fetching them from an online server. This means:

- **Works offline**: No internet connection needed
- **Faster results**: No waiting for server responses
- **Reduced data usage**: Saves on mobile data
- **Morocco-specific**: Uses official calculation methods endorsed by Morocco's Ministry of Islamic Affairs

## Enabling Local Prayer Calculations

### Step 1: Open Settings

1. Tap the menu icon (☰) in the top-left corner of the app
2. Select "Settings" from the menu
3. Scroll down to the "Prayer Times" section

### Step 2: Enable Local Calculations

1. Find the "Enable Local Calculations" option
2. Toggle the switch to **ON** (green)
3. The app will immediately start using local calculations

### Step 3: Choose Your Preference

After enabling local calculations, you can choose how the app should use them:

1. **Prefer Local Over API**: 
   - The app will use local calculations first
   - Only falls back to online API if local calculation fails
   - Best for: Users with limited internet or who want fastest response

2. **API First (Default)**:
   - The app will try online API first
   - Falls back to local calculations if API fails
   - Best for: Users with reliable internet who want the most up-to-date times

## Understanding the Calculation Method Indicator

The prayer times widget now shows how your prayer times were calculated:

### API Indicator
- Shows: **"API"** next to the calculation method
- Means: Prayer times were fetched from online server
- Appears when: You have internet and API is available/working

### Local Indicator
- Shows: **"Local"** next to the calculation method
- Means: Prayer times were calculated on your device
- Appears when: You're using local calculations or API is unavailable

- Uses Morocco's official prayer time calculation method (18° Fajr, 17° Isha)

## Troubleshooting

### Local Calculations Not Working

**Problem**: Local calculations are enabled but prayer times still show "API"

**Solutions**:
1. Check your internet connection - if API is available, it may be used first
2. Try "Prefer Local Over API" setting to prioritize local calculations
3. Restart the app to ensure settings take effect
4. Check that location permissions are enabled

**Problem**: Prayer times seem inaccurate

**Solutions**:
1. Ensure your location is set correctly in the app
2. Check that you're in the correct region for Morocco
3. Compare with official local prayer times
4. Report any discrepancies to the support team

### Settings Not Saving

**Problem**: Local calculation settings don't save after restart

**Solutions**:
1. Check that the app has storage permissions
2. Clear app cache and restart
3. Reinstall the app if the problem persists

## Frequently Asked Questions

### Q: Are local calculations as accurate as API calculations?

**A**: Yes! Local calculations use the same mathematical formulas as the API, with Morocco-specific adjustments approved by religious authorities. In some cases, local calculations may be even more accurate because they include regional adjustments.

### Q: Do I need internet for local calculations?

**A**: No! That's the main benefit. Once enabled, local calculations work completely offline without any internet connection.

### Q: Will local calculations work outside Morocco?

**A**: Yes! Local calculations work globally, but the Morocco-specific features (like official calculation methods and regional adjustments) only apply when you're physically in Morocco.

### Q: How much battery does local calculation use?

**A**: Very little! Local calculations are much more battery-efficient than making network requests to servers. You'll actually save battery life by using local calculations.

### Q: Can I switch between local and API calculations?

**A**: Yes! You can change your preference at any time in Settings, or disable local calculations entirely to use only API.

### Q: What happens to my prayer notifications?

**A**: Prayer notifications work exactly the same way whether using local or API calculations. The system ensures you always get notified on time, regardless of the calculation method.

## Tips for Best Results

### 1. Enable Location Services
For accurate Morocco-specific adjustments:
- Go to your phone's Settings → Apps → HaramBlur → Permissions
- Ensure Location permission is enabled
- Choose "Allow all the time" for best results

### 2. Set Your Preferred City
If you're in Morocco:
- Go to Settings → Location → Select City
- Choose your city from the list
- This ensures the most accurate regional adjustments

### 3. Use "Prefer Local" for Offline Use
If you frequently travel or have poor internet:
- Enable "Prefer Local Over API" in settings
- This ensures you always have prayer times, even without internet

### 4. Keep Location Updated
If you travel between regions in Morocco:
- The app will automatically detect your new region
- Regional adjustments will update automatically
- No manual intervention needed
