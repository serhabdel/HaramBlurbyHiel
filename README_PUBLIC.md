# HaramBlur

[![Android](https://img.shields.io/badge/Android-API_25+-green.svg)](https://developer.android.com)
[![Kotlin](https://img.shields.io/badge/Kotlin-1.9+-blue.svg)](https://kotlinlang.org)
[![License](https://img.shields.io/badge/License-IOSL-orange.svg)](LICENSE)

Islamic content filtering for Android. Protecting your digital experience through intelligent, on-device content detection.

## 🌟 Features

- **Real-time Content Filtering** - Automatically detects and blurs inappropriate content
- **Privacy First** - All processing happens locally on your device
- **Islamic Features** - Prayer times, Quranic verses, and dhikr reminders
- **Battery Optimized** - Adaptive capture intervals to minimize battery impact
- **Customizable** - Adjust sensitivity, blur styles, and monitored apps

## 🚀 Getting Started

### Requirements
- Android 7.1+ (API 25+)
- 2GB RAM minimum (4GB recommended)
- 100MB free storage

### Installation

1. Download the latest APK from [Releases](../../releases)
2. Enable "Install from Unknown Sources" in Settings
3. Install the APK
4. Enable Accessibility Service when prompted

### Setup

1. Open HaramBlur
2. Grant Accessibility Service permission
3. Configure your preferences
4. The app runs automatically in the background

## 🛠️ Tech Stack

- **Language**: Kotlin
- **UI**: Jetpack Compose
- **Architecture**: MVVM with Hilt DI
- **ML**: TensorFlow Lite
- **Database**: Room
